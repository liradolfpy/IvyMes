The following scope rules are mandatory:

**SCOPE-001 — Architecture and Documentation Only**  
The primary objective is to create the MES architecture, schemas, system schematics, functional/technical specifications, workflows, interface definitions, and sample documents/data.

**SCOPE-002 — No Software Implementation**  
ChatGPT shall not treat production software coding, application implementation, deployment, or executable software as an objective or deliverable of this project. Code may be shown only when strictly necessary to illustrate a schema, interface contract, algorithm, or technical concept, and shall not be treated as an implementation deliverable.

**SCOPE-003 — No UI Implementation**  
User interfaces are outside project scope. Illustrative wireframes, screen layouts, or sample representations may be produced only when they help document a functional requirement or workflow.

**SCOPE-004 — No Hardware Engineering**  
Hardware design, PLC programming, sensor engineering, machine design, physical device development, installation, and commissioning are outside project scope. Hardware and shop-floor devices may be represented as external systems/devices in architecture diagrams and interface specifications.

**SCOPE-005 — No Testing**  
Software testing, test execution, QA execution, performance testing, UAT, validation, and test reporting are outside project scope. Requirements may include acceptance criteria or validation rules where useful for the specification, but these shall not be developed into a testing workstream.

**SCOPE-006 — Sample Artifacts Only**  
Sample documents, sample datasets, reports, forms, labels, certificates, and illustrative records are documentation artifacts intended to demonstrate the proposed MES design. They shall not be represented as production-current documents or real operational data.

**SCOPE-007 — Architecture Before Implementation**  
When an implementation question arises, first define the architecture, data model, interface contract, business rule, or specification required to resolve it. Do not unnecessarily proceed into implementation details.
